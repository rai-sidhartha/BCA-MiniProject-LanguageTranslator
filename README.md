# Language Translator

## Project Abstract

Language Translator is a web-based application that allows users to translate text from one language to another. The application provides a simple and user-friendly interface for entering text, selecting languages, and viewing the translated result.

## Features

* Text translation
* Source language selection
* Target language selection
* Translated text output
* Simple and user-friendly interface
* Responsive design

## Technology Stack

* HTML5
* CSS3
* JavaScript
* Translation API
